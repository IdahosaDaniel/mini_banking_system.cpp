# Mini Banking System (C++)

A simple command-line banking application developed in C++ to practise programming fundamentals and simulate basic banking operations.

## Features

- Create and manage user accounts
- Deposit money into an account
- Withdraw money from an account
- Check account balances
- Support multiple users

## Technology Used

- **Programming Language:** C++
- **Interface:** Command-line interface (CLI)

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Compile the C++ source file using a C++ compiler such as `g++`.
4. Run the compiled program.

Compile the program:

```bash
g++ mini_banking_system.cpp -o mini_banking_system
```

Run on Windows:

```bash
mini_banking_system.exe
```

Run on Linux/macOS:

```bash
./mini_banking_system
```
